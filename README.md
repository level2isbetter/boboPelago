# boboPelago
Archipelago implementation for the pet raising game, Bobo Bay :)

Features
--------
- Competitions are sent into the AP pool and unlocked in a set order with "Progressive Competitions"
- Sagas are sent into the AP pool as well, unlocked with "Progressive Sagas"
- Public works are sent into the AP pool and randomized
- Multiple game options such as snack multiplier, unlimited snacks, and maybe more to come?
- 2 goals, Big Jam and Power Gary

Setup
-----
### Prerequisites
- Archipelago (0.6.7 or higher) [[Install](https://github.com/ArchipelagoMW/Archipelago)] [[Guide](https://archipelago.gg/tutorial/Archipelago/setup/en)]
- Bobo Bay game from Steam
